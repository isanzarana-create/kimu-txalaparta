# Kimu Txalaparta · web

Web estática bilingüe (ES / EU) de Kimu Txalaparta. Gestión y contratación: Musubigara®.

- `public/` se publica tal cual en Netlify (sin compilación).
- Para cambiar textos: edita `tools/build.py` y ejecuta `python3 tools/build.py`.
- Rider técnico en PDF: `python3 tools/rider.py`.
- Lo pendiente aparece en la web con borde discontinuo (clase `.tbd`).
- Formulario de contratación: Netlify Forms (`contratacion`). Activa las notificaciones por correo en Netlify → Forms.
